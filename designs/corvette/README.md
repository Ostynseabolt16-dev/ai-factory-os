# Corvette design assets

Live Corvette masters / Printify uploads live on the **Mac shop folder** (`~/ai/designs/…`), not in this GitHub repo historically.

When syncing Corvette PNGs into Git, put them here:

```
designs/corvette/
  *_UPLOAD_TO_PRINTIFY.png
  *_master.png / collection masters
  banner/ (optional)
```

Do **not** dump sticker or pickleball files in this folder.
