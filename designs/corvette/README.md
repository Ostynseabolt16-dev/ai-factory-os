# Corvette design assets

Corvette masters and Printify uploads belong here.

If your Mac still has Corvette PNGs in the flat `designs/` folder, move them into this directory:

```
designs/corvette/
  corvette_*_UPLOAD_TO_PRINTIFY.png
  c*_collection*.png
  cozy_orbit_etsy_*.png
  banner/   (optional)
```

Do **not** put pickleball or sticker files in this folder.
